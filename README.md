# HR Analytics Dashboard - Employee Retention & Performance

## 📌 Project Objective
The goal of this project is to analyze HR data to improve employee satisfaction, improve retention rates, and optimize the recruitment process.

## 🛠️ Technical Stack
- **Data Extraction:** Microsoft SQL Server
- **Data Transformation:** Power Query Editor
- **Data Modeling:** Star Schema (Fact and Dimension tables)
- **Analysis & Calculations:** DAX (Data Analysis Expressions)
- **Visualization:** Power BI

## 💡 Key Insights & Recommendations
- **Overtime Drives Attrition:** Employees working overtime have a significantly higher attrition rate (~30%+). *Recommendation: Cap overtime and hire additional support.*
- **Early Tenure Risk:** Most exits happen in the 0-1 year bucket. *Recommendation: Implement a structured 90-day onboarding and mentorship program.*
- **Stock Options Matter:** Employees with 0 stock options leave at nearly 40%. *Recommendation: Introduce a basic ESOP/equity plan for junior employees.*
- **Young Talent is Leaving:** The 18-25 age group shows the highest attrition. *Recommendation: Review entry-level compensation and growth paths.*
